# cursor-dotfiles

Cursor setup for Tarang Sharma. This repo is the backup that can move to another laptop.

The live folder on this machine is `C:\Users\trngs\.cursor`.

Tracked here:

- `rules/` standing rules
- `MEMORY.md` notes that follow every workspace
- `mempalace/` identity, wake-up, wings, and the Chroma store in `mempalace/palace/`
- `skills/` personal skills
- `mcp.json` MCP servers, with no tokens in the file

Not tracked: extensions, worktrees, chat transcripts, and caches. Those are large and belong to this machine.

After a clone, copy this repo onto `C:\Users\trngs\.cursor` on the new laptop. The MemPalace config points at `C:\Users\trngs\.cursor\mempalace\palace`.
